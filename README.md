## ✨ Features

- 🛍️ **Product catalog** with category filters and live search
- 📄 **Product detail page** with fragrance notes (top / middle / base)
- 🛒 **Shopping cart** — add, remove, adjust quantity
- 📱 **Fully responsive** — mobile, tablet, desktop
- 🎨 **Dark luxury UI** — Cormorant Garamond + DM Sans, gold accents

---

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Start dev server
npm run dev

# Build for production
npm run build
```

## 🛠️ Tech Stack

| Tool | Purpose |
|------|---------|
| React 18 | UI framework |
| TypeScript | Type safety |
| React Router | Client-side routing |
| Vite | Build tool |
| Context API | Cart state management |

## 📸 Pages

| Route | Description |
|-------|-------------|
| `/` | Home — product grid with filters |
| `/product/:id` | Product detail with notes |
| `/cart` | Shopping cart & summary |
